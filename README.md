# Superstore EDA Project

## Project Overview
This project explores the Superstore dataset using Python for exploratory data analysis. The analysis focuses on sales performance, profit distribution, category and sub-category performance, regional difference, time trends, and the impacts of discount on profitability. The goal is to identify key business patterns and risk factors in the dataset.

## Tools Used
- Python
- pandas
- seaborn
- matplotlib
- Jupyter Notebook

## Analysis Topics
1. Data overview
2. Missing value check
3. Category and sub-category analysis
4. Sales and profit distribution
5. Regional analysis
6. Time trend analysis
7. Discount analysis
8. Cross-dimensional analysis

## Key Findings
- The dataset contains 9,994 rows and 12 columns, with no missing values.
- Sales are highly right-skewed, indicating that most orders have relatively low sales values
- Profit is concentrated around zero and fluctuate significantly over time.
- The West region has the highest number of orders, total sales, and total profit.
- Higher discount levels are associated with lower profit.
- Profitability varies significantly across categories, regions, and sub-categories
